7.2 CI / optional cloud (documented in repository)

File .github/workflows/deploy-web-vercel.yml (manual workflow_dispatch):

  • Runner: ubuntu-latest.
  • Steps: actions/checkout, subosito/flutter-action (stable), flutter pub get, flutter build web --release with AUTH_API_URL from GitHub Actions secret.
  • Deploy target: Vercel (requires VERCEL_TOKEN secret); comments reference example API on Railway and CORS alignment.

Important: Actual production URLs depend on your configured secrets and Vercel project; they are not hard-coded in application source.
