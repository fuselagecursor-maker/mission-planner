4. Notes & scope

  • Missions table: PostgreSQL missions exists (see init.sql / migrate.js); no mission CRUD REST routes are implemented in this repository.
  • GCS data: Map and telemetry displays include simulated or placeholder logic unless otherwise wired.
  • Additional sequences (e.g. registration POST only) can be documented separately; Figures 2–3 cover splash/login and admin moderation.
